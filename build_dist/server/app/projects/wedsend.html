WedSend

Wedding & Event Guest Management Platform

A professional wedding and event guest management platform designed to simplify guest management, digital invitation workflows, and bulk event communication.

View GitHub SourceVerified Source Code Available

Technologies Used

Next.jsReactTypeScriptTailwind CSSFastifySupabasePostgreSQLWhatsApp Cloud API
The Business Problem

Couples and event planners face chaotic coordination across spreadsheets, paper lists, and manual phone contacts, resulting in misplaced RSVPs and high communication overhead.

The Engineering Solution

WedSend unifies the entire guest lifecycle into a single operational hub: automated roster parsing from PDF documents, verified database storage, and instant bulk delivery with confirmation telemetry via WhatsApp Cloud API.

Verified Implemented Features

User authentication and protected role workspaces
Comprehensive event creation and schedule planning
Granular guest-list management with RSVP statuses
Automated PDF guest-list extraction and parsing
Campaign management and automated invitation broadcast
Real-time WhatsApp Cloud API messaging integration
Live message delivery and read tracking telemetry
Centralized event overview and dashboard analytics
System Architecture
Step 01Next.js & Tailwind CSS Frontend (Responsive Organizer Portal)
Step 02Fastify Microservice (High-throughput API & Webhook Ingestion)
Step 03Supabase PostgreSQL (Event records, RSVP telemetry, & Auth)
Step 04Meta WhatsApp Cloud API (Automated bulk broadcast & delivery receipts)

Development Challenges & Solutions

Handling rate limits and webhooks from Meta's WhatsApp Cloud API while keeping database states in sync under concurrent delivery queues, resolved through Fastify asynchronous task processing.

Verified Results & Impact

Streamlined guest communication workflow, eliminated manual phone messaging, and delivered real-time RSVP visibility for event organizers.
